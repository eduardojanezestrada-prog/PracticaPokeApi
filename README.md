# 🔴 PracticaPokeApi

Una aplicación web interactiva desarrollada para practicar la integración con la API REST pública de Pokémon ([PokeAPI](https://pokeapi.co/)). El proyecto permite explorar, buscar y visualizar información detallada sobre distintos Pokémon en tiempo real.

---

## 🚀 Características

- 🔍 **Búsqueda dinámica:** Permite buscar Pokémon por generación.
- 📋 **Visualización de tarjetas:** Muestra información clave de cada Pokémon (imagen/sprite, tipos, estadísticas básicas, habilidades, peso y altura).
- 🎨 **Diseño adaptable (Responsive):** Interfaz optimizada para dispositivos móviles, tablets y de escritorio.
- ⚡ **Paginación / Carga asíncrona:** Navegación entre distintas páginas o lista de Pokémon utilizando peticiones asíncronas (`fetch` / `axios`).

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **API Externa:** [PokeAPI](https://pokeapi.co/)
* **Control de Versiones:** Git & GitHub

*(Si utilizaste algún framework como React, Angular, Vue o utilidades como Bootstrap / Tailwind CSS, puedes añadirlos a la lista).*
